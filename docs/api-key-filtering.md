# API 密钥筛选

`GET /api/token/search` 支持组合使用 `keyword`、`token`、`group`、`status`。状态为 1（启用）、2（禁用）、3（过期）、4（额度耗尽），多个状态以逗号分隔。查询始终限定当前用户，先筛选再分页；total 是完整匹配数量。

列表和搜索响应的 data.facets 返回 groups、statuses 两个计数字典。统计覆盖当前用户全部未删除密钥，不依赖当前页。分组计数保留名称、密钥、状态条件，但忽略已选分组；状态计数保留名称、密钥、分组条件，但忽略已选状态。内部分组 parnter 不出现在分组统计中。

页面直接显示后端计数，缺失选项显示 0，不再用表格当前页计算。切换筛选会回到第一页，状态筛选参与请求和缓存键。
