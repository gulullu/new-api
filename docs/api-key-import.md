# API 密钥模板导入

在 API 密钥页点击“导入 API 密钥”，按“导入与编辑 → 确认配置 → 获取密钥”完成创建。

## 数据与模板

- 每一行创建一个新密钥，名称可以代表人员、项目、设备或其他用途。
- 支持粘贴名称列表、粘贴 Excel 等表格中的数据，以及导入 Excel XLSX、UTF-8 CSV/TXT；每次 1–100 行，文件最大 1 MiB。
- 默认下载 Excel 模板，分组列内置当前账号可用分组的下拉（100 行），分组数据表隐藏，不展示说明文字；有效期列提供 7、30、never 快选，也可输入具体日期。名称与日期按文本保存，保留前导零。
- Excel 中只需填写名称，其他空白字段使用导入页面当前默认配置。创建前须核对预览，额度单位以下载时列标题和当前页面单位为准。
- 在页面中用下拉选择分组，设置每个密钥的额度、有效期、模型限制及 IP 白名单。
- 单元格留空时继承模板默认值，填写后覆盖该行。额度为 0 和不限额是两种不同配置。
- 模板按当前用户保存，最多 20 个，只保存默认配置，不包含名称列表或密钥。
- 模板额度以系统额度单位保存，因此切换页面显示币种不会改变模板实际额度。

CSV 模板列名支持英文或对应中文，列顺序可以调整，名称列必须保留：

| 英文列名 | 中文列名 | 填写规则 |
| --- | --- | --- |
| name | 名称 | 必填；沿用已有密钥的 50 字节限制 |
| group | 分组 | 系统分组标识；`auto` / `跨分组` 表示使用全局分组顺序 |
| quota | 额度 | 当前页面显示单位下的非负金额，或 `unlimited` / `不限额` |
| expiry | 有效期 | `7`、`30`、`never` / `永不过期`，或 `YYYY-MM-DD` |
| models | 模型限制 | 逗号分隔；`*` 表示不限制 |
| ips | IP白名单 | 逗号或换行分隔的 IP/CIDR；`*` 表示不限制 |

相对有效期在进入确认页时换算为具体截止时间，确认页会展示最终时间。指定日期使用浏览器当地时区的当天结束时间。

包含逗号、换行或双引号的 CSV 单元格需按标准 CSV 规则加引号。使用下载的空模板填入内容最方便。名称列表也可以直接每行粘贴一个名称。

## 校验与创建

- 同一批次内的重复名称、不可用分组、无效额度、过期日期或错误 IP 会阻止创建。
- 若账号已有同名密钥，确认页会提示。只有明确勾选仍要创建，才会新增同名密钥；已有密钥不会被覆盖。
- 创建使用单个数据库事务。任意一行失败，整批回滚。单个创建与导入共用用户锁，避免并发突破密钥数量上限。
- 每次提交带独立请求标识。网络结果不确定时点击“重试本次导入”，服务器返回原批次结果，不重复创建。
- 导入结果可以复制或导出 CSV。完整密钥仅保存在当前弹窗内存及用户主动导出的文件中，不写入模板或浏览器本地存储。数据库复用原有密钥存储，导入记录仅保存关联 ID 和请求摘要。
- CSV 导出会转义公式前缀，降低表格软件将名称等数据当成公式执行的风险。

## 接口

以下接口均要求当前用户登录，并按用户隔离：

- `POST /api/token/import-template.xlsx`：下载含分组下拉的 Excel 模板，分组由服务端按当前用户权限生成，内部分组 `parnter` 对所有账号隐藏（包括管理员）；用户侧分组下拉同样隐藏。
- `POST /api/token/batch/import/file`：解析 XLSX 并返回待编辑内容，不创建密钥；限制文件和解压大小，拒绝公式。
- `POST /api/token/batch/import/preview`：校验配置并返回同名列表和剩余名额。
- `POST /api/token/batch/import`：事务创建或返回相同请求标识的已有结果，响应禁止缓存。
- `GET /api/token/import-templates`：读取自己的模板。
- `POST /api/token/import-templates`：保存模板。
- `DELETE /api/token/import-templates/:id`：删除自己的模板。

迁移新增 `token_import_batches` 和 `token_import_templates` 两张表，不更改现有密钥表结构。
